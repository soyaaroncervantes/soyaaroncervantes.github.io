# Agent Context — Core

The `core` directory contains the application entry point, routes, layouts, providers, and stores — everything that is not feature-specific.

---

## Directory Structure

```
src/core/
  providers/
    AppProvider.tsx       — root provider composition
    ThemeProvider.tsx     — M3eTheme wrapper, driven by useThemeController
  routes/
    __root.tsx            — TanStack Router root route: locale redirect + AppProvider
    _rootLayout/
      index.tsx           — redirects / → /v2
      v1/
        index.tsx         — V1Page component
      v2/
        index.tsx         — V2Page component
```

---

## Routing

Routes are **file-based** using TanStack Router. The file path under `routes/` maps directly to the URL.

| File | Route | Notes |
|---|---|---|
| `__root.tsx` | `/` (root) | Handles locale redirect via `beforeLoad` |
| `_rootLayout/index.tsx` | `/_rootLayout/` | Redirects to `/v2` by default |
| `_rootLayout/v1/index.tsx` | `/v1/` | V1 page |
| `_rootLayout/v2/index.tsx` | `/v2/` | V2 page |

**How to create a new route:**

1. Create a file under `src/core/routes/` — the path matches the URL
2. Use `createFileRoute` with the exact path string:

```tsx
import { createFileRoute } from '@tanstack/react-router'

export const Route = createFileRoute('/_rootLayout/v3/')({
  component: V3Page,
})
```

3. TanStack Router auto-generates `src/routeTree.gen.ts` — never edit this file manually

## Layouts

All pages use the `Layout` compound from the theme feature (or a similar wrapper).

- `Layout.Screen` — full viewport wrapper (`height: 100dvh`, `display: flex`)
- `Layout.Content` — scrollable content area

```tsx
<Layout.Screen>
  <Nav .../>
  <Layout.Content>
    {/* page content */}
  </Layout.Content>
</Layout.Screen>
```

## Providers

All providers are composed in `AppProvider.tsx`. To add a new provider:

1. Create the provider in `src/core/providers/` (or in the relevant feature)
2. Wrap it inside `AppProvider.tsx` in the correct order (outer providers first)

```tsx
// src/core/providers/AppProvider.tsx
export const AppProvider = ({ children }: PropsWithChildren) => (
  <ThemeProvider>
    <QueryClientProvider client={queryClient}>
      <I18nProvider>
        {children}
      </I18nProvider>
    </QueryClientProvider>
  </ThemeProvider>
)
```

## Redirect Rules

| Trigger | Behavior | Location |
|---|---|---|
| Any URL | Locale redirect (add `/en` prefix if needed) | `__root.tsx` `beforeLoad` via `shouldRedirect` |
| Navigate to `/_rootLayout/` | Redirect to `/v2` | `_rootLayout/index.tsx` `beforeLoad` |

**Locale redirect logic:**

```ts
// src/core/routes/__root.tsx
beforeLoad: async () => {
  const decision = await shouldRedirect({ url: window.location.href })
  if (decision.redirectUrl) {
    throw redirect({ href: decision.redirectUrl.href })
  }
}
```

- `shouldRedirect` is from `@/paraglide/runtime.js` (auto-generated — do not modify)
- Base locale `es` has no URL prefix; `en` uses `/en/` prefix

---

## Rules

- Never edit `src/routeTree.gen.ts` — it is auto-generated by TanStack Router
- Never edit `src/paraglide/` — auto-generated by the Vite i18n plugin
- Add all new providers to `AppProvider.tsx` — never wrap providers inside page components
