# Agent Context — Icon Components

> **Global references:** `src/AGENTS.md`, `src/features/theme/components/AGENTS.md`

The icon feature exposes exactly one public icon API: `Theme.Icon`.

---

## Public API

Use:

```tsx
<Theme.Icon name="person" />
<Theme.Icon name="github" aria-label="GitHub" />
```

Do not use:

```tsx
<Icon.Svg ... />
<Icon.Material ... />
<Icon.Slot ... />
```

The renderer choice (Material vs sprite) is an implementation detail and must stay internal.

---

## Internal dispatch pattern

- `Icon.tsx` receives `name`.
- `registry.ts` decides whether the name is a sprite icon.
- If sprite: render `<svg><use href="...#id" /></svg>`.
- Otherwise: render `<M3eIcon>{name}</M3eIcon>`.

`registry.ts` imports generated ids from `icon-names.generated.ts` (generated by `vite-plugin-svg-sprite-names-typescript`).

---

## Rules

- Keep `Theme.Icon` as the only semantic API.
- Never branch icon renderer in consumer components.
- Never reintroduce `Icon.Svg` as public API.
- If new sprite ids are added to `public/icons.svg`, regenerate/check `icon-names.generated.ts`.
