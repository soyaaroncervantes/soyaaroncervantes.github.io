# Agent Context — i18n Feature

The `i18n` feature provides internationalization support for the portfolio using [Paraglide JS](https://inlang.com/m/gerre34r/library-inlang-paraglideJs).

Supported locales: `es` (base) and `en`. Locale detection strategy: `["url", "localStorage", "preferredLanguage", "baseLocale"]`.

---

## Feature Structure

```
messages/
  es.json               — Spanish messages (base locale)
  en.json               — English messages

src/features/i18n/
  hooks/
    useI18nController.ts  — ViewController: reads active locale, exposes setLocale
  providers/
    I18nProvider.tsx      — Context provider + useI18n() hook

src/paraglide/           — AUTO-GENERATED by Vite plugin. NEVER edit manually.
  messages.js            — Typed message functions
  runtime.js             — Locale runtime (shouldRedirect, setLocale, etc.)
```

---

## How to Add a Message

1. Add the key to `messages/es.json`:

```json
{
  "hello_world": "Hola mundo"
}
```

2. Add the same key to `messages/en.json`:

```json
{
  "hello_world": "Hello world"
}
```

3. The Vite plugin auto-generates typed functions in `src/paraglide/messages.js`. No manual step needed.

---

## How to Use a Message in a Component

Import the generated function directly from `@/paraglide/messages`:

```tsx
import { hello_world } from '@/paraglide/messages'

export const MyComponent = () => (
  <span>{hello_world()}</span>
)
```

- Functions are named after the message key
- They automatically return the message for the active locale
- No hook or provider required for rendering messages

---

## How to Read the Active Locale

Use `useI18n()` from `I18nProvider`:

```tsx
import { useI18n } from '@/features/i18n/providers/I18nProvider'

export const LocaleDisplay = () => {
  const { locale } = useI18n()
  return <span>{locale}</span>
}
```

`useI18n()` throws if called outside `I18nProvider`. It is provided by `AppProvider` via `src/core/providers/`.

---

## How to Change the Active Locale

```tsx
import { useI18n } from '@/features/i18n/providers/I18nProvider'

export const LangToggle = () => {
  const { locale, setLocale } = useI18n()
  return (
    <button onClick={() => setLocale(locale === 'es' ? 'en' : 'es')}>
      {locale}
    </button>
  )
}
```

## Locale Redirect (Root Route)

The root route `__root.tsx` handles locale redirect on navigation:

```ts
beforeLoad: async () => {
  const decision = await shouldRedirect({ url: window.location.href })
  if (decision.redirectUrl) {
    throw redirect({ href: decision.redirectUrl.href })
  }
}
```

- `shouldRedirect` is imported from `@/paraglide/runtime.js` (auto-generated)
- Redirects to the correct locale URL prefix (e.g. `/en/v1`) when needed
- Base locale `es` has no URL prefix

---

## Rules

- **Never edit `src/paraglide/`** — all files there are auto-generated by the Vite plugin on build/dev
- Always add messages to **both** `es.json` and `en.json` at the same time
- Use `Nullable<string>` from `@/shared/base.types` if a message key is conditionally absent
